# Fundamentals

Core Python language features, one topic per file. Run any file directly:

```bash
python 01_variables.py
```

| `01_variables.py` | Names, assignment, multiple assignment |
| `02_data_types.py` | `int`, `float`, `str`, `bool`, `None` |
| `03_type_casting.py` | Converting between types |
| `04_input_output.py` | `print`, `input`, formatting |
| `05_operators.py` | Arithmetic, comparison, logical, bitwise, assignment |
| `06_strings.py` | Indexing, slicing, concatenation |
| `07_string_methods.py` | Common `str` methods |
| `08_lists.py` | Mutable sequences |
| `09_tuples.py` | Immutable sequences, unpacking |
| `10_sets.py` | Unique unordered collections |
| `11_dictionaries.py` | Key-value pairs |
| `12_conditionals.py` | `if` / `elif` / `else` |
| `13_loops.py` | `for`, `while`, `range` |
| `14_break_continue_pass.py` | Loop control |
| `15_functions.py` | `def`, arguments, `return` |
| `16_scope.py` | Local vs global names |
| `17_lambda.py` | Anonymous functions |
| `18_list_comprehensions.py` | Building lists in one expression |
| `19_modules.py` | `import` and `from` |
| `20_random_module.py` | `random` for numbers and choices |
