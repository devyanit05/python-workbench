# Interview Questions

Classic screening problems. Each file starts with a problem card (difficulty, companies, approaches, complexity), then the solutions. Run any file directly:

```bash
python 01_swap_numbers.py
```

The idiomatic Python version of a trick, when there is one, lives in `01_fundamentals/`.

| File | Problem |
| --- | --- |
| `01_swap_numbers.py` | Swap two numbers without a temp variable |
| `02_fibonacci.py` | Fibonacci sequence (loop and recursion) |
| `03_factorial.py` | Factorial of n |
| `04_prime_number.py` | Check whether a number is prime |
| `05_palindrome.py` | Check whether a string or number is a palindrome |
| `06_reverse_string.py` | Reverse a string |
| `07_string_length.py` | String length without `len()` |
| `08_armstrong_number.py` | Armstrong number |
| `09_even_odd.py` | Even or odd |
| `10_positive_negative.py` | Positive, negative, or zero |
| `11_sum_of_n_numbers.py` | Sum of first n natural numbers |
| `12_maximum_in_list.py` | Largest value in a list |
| `13_second_largest.py` | Second largest value in a list |
| `14_remove_duplicates.py` | Remove duplicates, keep order |
| `15_anagram.py` | Whether two strings are anagrams |
| `16_missing_number.py` | Missing number in 1..n |
| `17_merge_sorted_lists.py` | Merge two sorted lists |
| `18_binary_search.py` | Binary search |
| `19_bubble_sort.py` | Bubble sort |
| `20_frequency_counter.py` | Count character / item frequency |
